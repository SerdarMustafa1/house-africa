# Product — House Africa MTÜ Website

## Project Purpose
Static marketing/informational website for House Africa MTÜ, a registered Estonian non-profit (Mittetulundusühing) that connects African communities and the diaspora in Estonia through culture, education, and dialogue.

## Value Proposition
Provides an accessible, professional online presence for the organisation — enabling community members, partners, and the public to learn about the NGO, view events and gallery content, and make direct contact.

## Key Features
- **Hero section** — full-viewport branded landing with CTA buttons
- **About section** — organisation description with placeholder for community photo
- **Mission / Core Pillars** — three-card grid (Culture, Education, Dialogue) with inline SVG icons
- **Community section** — activity cards (gatherings, cultural events, advocacy, networking)
- **Upcoming Event** — dedicated section with event image and badge
- **Photo Gallery** — responsive grid with lightbox (prev/next navigation, keyboard support)
- **Social / Stay Connected** — Facebook & Instagram links
- **Contact section** — address/email/phone details + front-end validated contact form
- **Sticky header** — scroll-aware shadow, active nav link highlighting
- **Mobile navigation** — hamburger menu with slide-in overlay
- **Back-to-top button** — appears after 400 px scroll
- **Scroll reveal animations** — IntersectionObserver-based fade-in with stagger on card grids
- **SEO & structured data** — Schema.org NGO markup, Open Graph tags, canonical URL

## Target Users
- African community members and diaspora living in Estonia
- Potential partners, sponsors, and collaborators
- General public interested in African culture in Estonia
- Journalists and researchers

## Use Cases
- Learn about the organisation's mission and activities
- View upcoming events and past gallery photos
- Contact the organisation via form or direct details
- Follow social media channels
- Discover community programmes and initiatives
